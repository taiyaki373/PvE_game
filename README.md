# EARTH GUARD — 地球防衛作戦

敵性ドローンの群れから湾岸都市を守る、ブラウザ用のオリジナル防衛シューティング。Canvas による3D風描画で、外部ゲームライブラリは不要です。

## 起動

```sh
npm ci
npm run dev
```

Node.js 22以上が必要です。ブラウザで http://localhost:5173 を開き、「出撃する」からソロ、「オンライン協力」から最大10人の協力プレイを開始します。ゲームと通信は同じポート5173で提供されます。HTTPSで公開する場合はWebSocketの転送にも対応したサーバーを使います。

## オンライン協力

1. 「オンライン協力」で隊員名と武器を選び、新しいルームを作ります。
2. 招待URLか6文字のルームコードを友達に共有します。
3. 参加者全員が「準備完了」にし、ルームリーダーが「全員で出撃」を押します。
4. 戦闘開始後はゲーム画面をクリックしてマウスを捕捉します。

同じルームの参加者は全員味方で、銃弾・ロケット・爆風による仲間へのダメージはありません。ロケットの自傷はソロと同じです。敵撃破時は全員が装備中の武器の予備弾を受け取ります。HP・弾薬・敵・射撃・攻撃・勝敗をサーバーが管理します。味方の姿・名前・HPは戦場にも表示されます。

各ウェーブの雑魚総数は `(5 + ウェーブ × 3) × 参加人数` です。最初は1人分だけ出現し、その後も1人分ずつ約8秒間隔で増援が到着します。現在の部隊を全滅させた場合は次の増援が約1秒後に到着します。最後にボスが1体出現し、HPは `ソロHP × (1 + 0.6 × (人数 - 1))` になります。残存敵が0でも、増援が残っている間は次ウェーブへ進みません。ソロも通常部隊の後にボスが増援として到着します。

途中参加にも対応します。参加者が増えると人数分の追加部隊を増援待ちに追加します。退出で人数が減った場合は次ウェーブから総数を減らします。リーダーが退出すると残った隊員へ権限を移します。戦闘不能の隊員は次ウェーブで復帰し、全員が戦闘不能になると敗北です。復帰時はマガジン1本と最低2回の撃破補給相当の予備弾を確保します。

オンラインの設定画面は自分の操作を止めますが、共有の戦闘は継続します。退出は設定画面から可能です。切断時には再参加画面を表示します。ルームはサーバーのメモリに保持され、最後の1人が退出したときに削除されます。サーバー再起動時にもルームはリセットされます。

## 操作

- WASD：移動
- マウス：上下左右の照準、左ボタン長押しで射撃
- 右ボタン長押し：ADS。スナイパーでは精密スコープ
- R：リロード
- Space：高速回避
- Esc / P：設定を開いて一時停止。「作戦を再開」で再開
- 矢印キー：前後移動、左右旋回（マウスロック非対応環境でも操作可能）

全5ウェーブを制圧すると勝利。6体撃破ごとに装甲が12、次ウェーブで20回復します。PCのキーボード・マウスと、スマートフォンのタッチ操作に対応しています。

敵の頭上に現在HP／最大HPを表示します。各ウェーブに1体のラウンドボスが出現し、画面上部に専用体力バーが表示されます。ボスは赤く発光して身を引いた後に突進し、HPが半分以下になると激昂して速くなります。横移動や回避で突進を避けてください。ボス撃破で装甲が25回復し、通常の敵とボスをすべて倒すと次ウェーブへ進みます。

## 武器と補給

| 武器 | 特性 | 装填 / 初期予備弾 | 撃破補給 |
| --- | --- | --- | --- |
| SMG | 高速連射、軽量、遠距離で大きく威力低下 | 40 / 160 | 14発 |
| アサルトライフル | 中距離向け、連射・威力・精度のバランス型 | 30 / 120 | 10発 |
| スナイパー | 高威力、長射程、ADS時に精密照準、低連射速度 | 5 / 25 | 2発 |
| ロケットランチャー | 飛翔弾、直径8mの爆風、単発装填、リロード2.3秒 | 1 / 8 | 1発 |

全武器の弾薬は有限です。リロードは予備弾から必要数だけ移し、敵撃破で選択した武器の予備弾を自動補給します。ボスは4倍補給。予備弾には上限があり、ウェーブ開始時に弾薬は回復しません。弾切れ時は設定から「装備を選んで再出撃」が可能です。銃弾・エネルギー弾・ロケットは建物で遮られ、爆風も壁越しには届きません。

ロケットの爆風半径は4m（直径8m）です。機体表面までの距離が半径の80％（3.2m）以内なら基本威力260の100％、外側20％なら75％（195）のダメージを与えます。直撃は100％で、敵の耐性・弱点による補正も適用されます。自分のすぐ近くで爆発すると自傷があります。

## 敵の攻撃

通常の敵も近接攻撃と回避可能なエネルギー弾で攻撃します。砲撃型の雑魚は遠距離を保ち、地面の赤い円で予告する範囲攻撃を使います。ボスは突進に加え、3方向のエネルギー弾と大型の範囲攻撃を使用します。攻撃名やカウントダウンは表示せず、射撃前は青白い発光、砲撃前は砲身の持ち上げと橙色の発光、突進前は赤い発光と身を引く動き、近接前は機体を傾ける動きで予告します。地面の赤い円が内側から満ちると着弾するので、移動して離脱してください。設定画面では攻撃・弾・予告の時間も停止します。

## 敵タイプと相性

| 敵 | 特性 | 有効な武器 |
| --- | --- | --- |
| スカウト（緑） | 小型・高速・蛇行 | SMG（1.6倍） |
| アサルト（水色） | 標準の射撃機 | アサルト（1.2倍） |
| ボンバード（黄） | 距離を保ち範囲砲撃 | スナイパー（1.5倍）、ロケラン（1.3倍） |
| バスティオン（橙） | 高HP・低速の重装甲 | ロケラン（1.65倍）、スナイパー（1.4倍）。SMGは0.5倍 |
| イージス（紫） | 80ポイントのシールド | シールドにはSMGが2倍。スナイパーは0.4倍 |
| ランサー（青） | 射撃予告後に高速弾、近づくと後退 | スナイパー（1.6倍）、アサルト（1.2倍） |

全武器で全タイプを撃破できます。相性は直接射撃とロケットの爆風の両方に適用されます。シールド破壊時の余剰ダメージは本体へ入り、シールドは再生しません。ボスはSMGに0.8倍、スナイパー・ロケランに1.2倍、アサルトに1倍です。装備選択画面の敵ガイドと、照準を合わせた敵の情報表示で相性を確認できます。

撃破時には機体色の爆発、光の衝撃波、重力で落下する装甲片、撃破表示と効果音が発生します。ボスはさらに大きい演出になります。演出はダメージを与えず、ゲームを一時停止すると演出も止まります。

「⚙ 設定」でマウス感度を0.20〜3.00倍に調整できます。変更は即時反映され、ブラウザに保存されます。建物は四面の窓、店舗入口、ベランダ、屋上設備を備え、距離に応じて描画する細部を調整しています。

```sh
npm run check
npm test
```

構文チェックと、武器・弾薬・補給・敵の攻撃・勝敗・設定の動作テストを実行します。フォントの取得ができない環境でも標準フォントで動作します。

通信テストはローカルポートを使って10個のWebSocketクライアントを接続します。ブラウザ検証を行う場合は、起動済みのゲームサーバーに対して以下を実行します。

```sh
npx playwright install --with-deps chromium
npm run test:browser
```

2つの独立したブラウザで招待・準備完了・同期・射撃・移動・設定を確認します。`node tests/browser-smoke.cjs https://公開URL` で公開環境も検証できます。

ロケランの基本威力は260です。敵は機体サイズに応じてビルと衝突し、通常移動・横移動・後退・ボス突進でも建物をすり抜けません。

## スマートフォンでの操作

横向き推奨です。左のスティックで移動、右側をスワイプして照準を動かします。左右の丸い「射撃」を長押しで連射、右の射撃ボタンはドラッグで照準も動かせます。「ADS」を長押しで精密照準。「装填」でリロード、「回避」で高速回避できます。右上の設定から照準感度を調整できます。ソロとオンライン協力の両方に対応し、縦向きでも遊べます。

`npm run test:mobile` でタッチ操作・縦横画面・オンラインをブラウザ検証します。
